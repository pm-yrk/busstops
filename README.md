# Bus Stops. one-shot build package

Place the contents of this folder at the root of the GitHub repository named `busstops`, then give Claude the text in `FIRST_PROMPT_FOR_CLAUDE.md`.

This package is a build specification, not application source code. It defines the complete product, architecture, data contracts, analytics, safeguards, tests, deployment requirements, and completion standard. Add credentials only as deployment secrets using the variable names chosen during implementation; never paste secret values into these documents or commit them.

The implementation agent must verify current provider documentation, licences, endpoints, and free allowances before deployment. The design is explicitly England-wide and must not be narrowed to a local proof of concept.
